# 按键与操作

## 实时查看

| 控制 | 行为 |
| --- | --- |
| K1 | 通用／零件模式切换；退出零件任务时取消当前处理并恢复 |
| K2 | 自动／手动阈值切换 |
| K3 | 原图、边缘、叠加三种视图循环 |
| 板载阈值加减键 | 手动阈值按 8 递增／递减；上下限饱和处理 |
| K4 | 零件模式下的参考示教、确认、检测和恢复 |

滤波、阈值及视图控制通过统一配置逻辑在帧边界生效；中值滤波默认开启，可通过已有串口运行时控制接口设置。零件和通用模式各自保留手动阈值。

## 通用模式

切换到通用模式，展示规范、对比清楚且彼此分离的数字或几何图案。系统对采样全画面中的独立目标分析、编号和标注；移动或移走目标会更新结果。多个数字分别识别，例如三个独立目标 1、2、3，不作为字符串 OCR 识别“123”。

结果每页显示 8 行，分页容量不代表只支持 8 个目标。通用目标记录队列为 2048 项，实际可检测数量受最小面积、分割质量和处理能力约束。

## 正常参考与待测检查

1. 切到零件模式，先放置正常件，保持工件完整进入画面。
2. 长按 K4 约两秒，看到“短按确认”后松开，再短按 K4。长按结束的松开动作本身不会提交参考。
3. 等待参考校验与特征保存完成并恢复实时。
4. 换上待测件，短按 K4。板端完成冻结、特征提取、定位、差异比较和结果发布。
5. 观察“待复核”候选和品红色标注，或者“未见候选／定位不足”等状态。结果页的有效更新帧率为 0，表示画面已冻结。
6. 再短按 K4 恢复实时；也可用模式键退出当前零件任务。

没有正常参考时短按 K4 会提示先存参考。重新下载、重新上电或配置改变后，应按屏幕状态重新示教。此提交不包含已验证的跨断电参考保存承诺。

## 连接与演示

沿用原有已验证接线。K4 顶层输入是 `key_detect_n_i`，项目管脚约束保留在 `project/Ti60_Demo.peri.xml`。JTAG 采用 6 MHz；无需为运行检测连接电脑算法程序。USB 串口可用于控制回读和 `0x53` 汇总诊断。

“未见候选”仅描述本次算法输出；实际缺口可能漏检，应结合图像复核。
