# 光稳智检 · FPGA 实时边缘与双模式视觉检测系统

**从实时图像到可交互检测结果，在一片 Ti60 FPGA 上完成。**

全国大学生嵌入式芯片与系统设计竞赛 FPGA 赛道，易灵思赛题四：**基于 FPGA 的实时图像边缘检测系统**。

光稳智检面向工业零件轮廓观察与教学演示，将实时图像增强、边缘显示、多目标数字与形状识别、正常参考示教、板端配准和异常候选提示集成在同一套硬件系统中。通过 FPGA 流水线、DDR 帧存储和共享片上存储协同，构建“采集—处理—识别—冻结—标注—恢复”的完整交互链路；日常演示和零件检测流程无需电脑参与推理。

本仓库为 **V16 全功能提交版**。源码、工程约束和下载位流均来自同一已完成 I3 时序签核的完整版本，保留通用识别和零件检测两种模式。

## 功能与技术亮点

| 能力 | 实现内容 |
| --- | --- |
| 实时图像处理 | AR0135 灰度采集、DDR 缓存、3×3 中值滤波、Sobel 梯度与方向、非极大值抑制及弱边连续性处理 |
| 三种显示 | 原图、边缘、原图与彩色边缘叠加；绿色强边、黄色弱边分层呈现 |
| 自适应控制 | 自动／手动阈值切换，通用与零件模式分别保存手动阈值，配置在帧边界统一生效 |
| 通用多目标识别 | 对采样全画面做连通区域分析，识别规范印刷体单个 0–9、基础几何形状和黑白方格；多目标分别编号和分页展示 |
| 板端正常参考示教 | 长按检测键并二次确认，保存正常工件参考和特征；参考数据通过身份与配置状态绑定 |
| 零件检测链路 | 冻结待测帧、提取特征、粗定位与原生姿态评估、方向直方图比较、差异区域生成、中文候选标注 |
| 高级边缘处理 | 保留冻结 ROI 的 FPGA Canny 处理能力；与实时 Sobel 显示通路配合使用 |
| 结果交互 | 中文状态、品红色加粗候选框、目标编号、结果分页、有效更新帧率、冻结结果及一键恢复 |
| 工程实现 | 共享 RAM、任务互斥借用、DDR 仲裁、跨时钟握手、任务身份校验和双缓冲结果发布 |

**设计重点：**

1. **一套硬件承载两类视觉任务。** 实时多目标识别和基于正常参考的零件检查共用计算与存储资源，兼顾演示丰富度和芯片容量。
2. **将比较流程下沉到 FPGA。** 正常参考、待测图像、特征、姿态和候选结果由板端状态机协调，形成独立可操作的检测流程。
3. **让结果对应同一张冻结图像。** 通过帧标识、参考标识、配置标识和结果双缓冲，避免旧结果覆盖新画面。
4. **兼顾图像细节与交互可读性。** 弱边连续性筛选保留浅纹理线索，品红色候选框与黄绿色边缘区分，中文界面直接呈现处理状态。

## 快速上板

1. 使用原有 AR0135、LVDS 和按键接线，在 Efinity Programmer 打开仓库中的全功能 `.bit`。
2. 选择 **JTAG、6 MHz** 下载。此操作为易失配置；本提交不把 JTAG 运行等同于 Flash 冷启动验证。
3. 初始进入零件模式；K1 切换通用／零件，K2 切换自动／手动阈值，K3 切换原图／边缘／叠加。
4. 零件模式下，放置正常件，长按 K4 约两秒，松开后再短按确认保存参考。
5. 换待测件，短按 K4 运行检测；结果页再次短按 K4 恢复实时画面。

详细操作见 [操作说明](docs/OPERATION.md)。位流 SHA256 见 [`firmware/SHA256.txt`](firmware/SHA256.txt)。
